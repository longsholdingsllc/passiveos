## How to use them

1. Install / start n8n (see `QUICKSTART.md` in this folder: self-hosted via `npx n8n` or Docker, or n8n Cloud), then open n8n (http://localhost:5678 for a local install).
2. In n8n, click **+** -> **Import from File** and select the desired `workflow.json` from one of the numbered folders in this directory.
3. Open the AI Agent node and add your LLM credentials (the shipped workflows use an OpenAI `gpt-4o-mini` Chat Model node), and add any trigger credentials named above (e.g. Gmail OAuth for workflows 02 and 04).
4. Follow that workflow's `setup.md` for configuration and customization, test with its `sample-payload.json` where provided (or the curl examples in `QUICKSTART.md`), then activate the workflow.
